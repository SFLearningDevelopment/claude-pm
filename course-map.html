Tier 1 — Single-context tasks
One document · One output · One feedback loop
Active

Each Tier 1 example gives Claude a single input — a brief, a metric dump, a backlog — and asks for one clear deliverable. The interaction runs 2–4 turns. These establish the prompting habits and output standards that make Tier 2 and Tier 3 work.

Tier 3 — Complex, cross-layer tasks
Ambiguous inputs · Competing priorities · Judgment-heavy outputs
Active

Tier 3 examples are the hardest and most realistic. Multiple workstreams, ambiguous inputs, and outputs that require genuine PM judgment to validate. Claude's value is in structuring the complexity — the PM's value is in knowing what to do with it.
